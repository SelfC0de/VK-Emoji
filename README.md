Описание:

VK Emoji by SelfCode - это удобное приложение для работы с эмодзи ВКонтакте.
С помощью этого инструмента вы сможете легко просматривать, загружать, конвертировать и сохранять ваши любимые смайлики из VK.
Приложение позволяет работать с hex-кодами эмодзи, а также конвертировать HTML-коды в нужный формат.
Добавьте разнообразия в вашу переписку или украсьте свой сайт с помощью оригинальных эмодзи!✨

Возможности:

Просмотр эмодзи: 🖼️ Предварительный просмотр смайлов из списка или по введенному hex-коду.

Загрузка эмодзи: ➕ Добавление новых emoji в список, загружая их по hex-коду.

Конвертация HTML: 🔄 Конвертация HTML-кодов emoji (например, &#128522;) в hex-коды для VK.

Сохранение: 💾 Сохранение изображений отдельных emoji на ваш компьютер.

Управление списком:

Поиск: 🔎 Быстрый поиск эмодзи по hex-коду в списке.

Удаление: 🗑️ Удаление ненужных emoji из списка.

Сохранение: 📝 Сохранение списка emoji в файл.

Загрузка: 📂 Загрузка списка emoji из файла.

Скачивание: ⬇️ Скачивание всех смайлов из списка.

Удобный интерфейс: 🎨 Простой и понятный интерфейс с минималистичным дизайном.

Многопоточность: ⚙️ Загрузка смайлов и другие операции выполняются в фоновом режиме, не вызывая зависания программы.

Анимированные уведомления: 🔔 Всплывающие анимированные уведомления для подтверждения действий.

Работа с VK API: 🌐 Использование официальной документации VK для получения emoji.

Как пользоваться VK Emoji.exe:

Запуск: Запустите приложение VK Emoji.exe.

Список эмодзи: Слева вы увидите список уже загруженных эмодзи в формате hex-кода (например, D83DDE0A).

Предпросмотр: Кликните на любой эмодзи в списке, чтобы увидеть его превью и HTML-код в правой части окна.

Добавление эмодзи по hex-коду:

В поле "Введите hex-код emoji" введите нужный код (например, D83DDE03).

Нажмите кнопку "Получить emoji", чтобы добавить смайл в список.

Добавление по HTML:
* В поле "Введите код вида 😊" введите HTML-код смайла.
* Нажмите кнопку "Конвертировать" код преобразуется в hex и вставится в строку.

Конвертация и сохранение:

Введите HTML код в поле "Введите код вида 😊".

Нажмите кнопку "Конвертировать и сохранить", html код сконвертируется в hex и смайл сохраниться.

Работа со списком:

Поиск: Используйте строку поиска над списком, чтобы отфильтровать emoji по их hex-коду.

Удаление: Выделите нужные emoji в списке и нажмите кнопку "Удалить emoji", чтобы убрать их.

Скачивание: Нажмите кнопку "Скачать все эмодзи", чтобы скачать и просмотреть все смайлы из списка.

Сохранение списка:

Нажмите кнопку "Сохранить список", чтобы сохранить текущий список emoji в файл VK Emoji.txt в папку VK Emoji.

Нажмите кнопку "Загрузить список", выберите файл VK Emoji.txt в папке VK Emoji.

Копирование HTML-кода:

Выберите смайл из списка и нажмите кнопку "Копировать код HTML" для копирования HTML-кода выбранного смайла.

Примечание:

Приложение использует официальные изображения эмодзи ВКонтакте.

Все сохраненные изображения и списки emoji будут находиться в папке "VK Emoji", которая создается рядом с VK Emoji.exe при первом запуске приложения.
